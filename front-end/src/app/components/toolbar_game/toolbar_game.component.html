🧩 LudoAccess - Règles du Jeu

🎯 Objectif :

Devinez le mot caché en tapant les lettres une par une dans l'ordre correct.

🕹️ Commandes :

  • Utilisez votre clavier pour entrer la prochaine lettre du mot.
  • Cliquez sur Pause pour interrompre la partie à tout moment.
  • Accédez aux Paramètres pour modifier vos options de jeu.

📜 Règles :

  • Seule la prochaine lettre correcte est acceptée.
  • Une mauvaise lettre est indiquée par un effet visuel rouge temporaire.
  • Le mot est terminé lorsque toutes les lettres sont correctement saisies !

💡 Astuces :

Restez concentré sur les lettres déjà proposées.
Prenez votre temps : mieux vaut être précis que rapide.
